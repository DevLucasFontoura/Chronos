# 🕰️ Chronos – Disciple Your Time

> **Chronos não mede tempo. Ele ensina disciplina.**

## 📋 Sobre o Projeto

Chronos é um time tracker simples, bonito e disciplinado que ajuda pessoas e times a dominarem o próprio tempo com foco, clareza e histórico real de trabalho.

### Problema que Resolve

Pessoas perdem tempo e não sabem exatamente onde ele foi gasto. As ferramentas atuais são:
- Complexas demais
- Feias ou pouco intuitivas
- Focadas só em empresas grandes

### Solução

Um time tracker onde:
- ⚡ O tempo só começa se houver intenção (projeto + tarefa)
- 📊 O histórico vira prova de trabalho
- 🎯 O usuário cria consciência real do uso do tempo

## 🎯 Público-Alvo

- Desenvolvedores
- Freelancers
- Designers
- Estudantes avançados
- Pessoas que trabalham por projeto

**Dor principal:** *"Trabalho o dia inteiro, mas não sei no que meu tempo foi gasto."*

## ✨ Proposta de Valor

- ✔️ **Simples** - Interface intuitiva e fácil de usar
- ✔️ **Rápido** - Sem complexidade desnecessária
- ✔️ **Sem distrações** - Foco no que importa
- ✔️ **Histórico claro** - Visualização completa do tempo trabalhado
- ✔️ **PDF profissional** - Exportação para comprovação de trabalho

## 🚀 Funcionalidades Mínimas (MVP)

### ⏱️ Controle de Tempo

- Iniciar tempo
- Pausar tempo
- Finalizar tempo
- Apenas um timer ativo por vez

### 📁 Projetos

- Criar projeto
- Editar projeto
- Arquivar projeto

### ✅ Tarefas

- Criar tarefa vinculada a um projeto
- Status da tarefa:
  - Não iniciada
  - Em andamento
  - Finalizada

### 🔗 Regra de Ouro

❌ **Não pode iniciar o timer sem selecionar Projeto + Tarefa**

### 📊 Histórico

- Lista de sessões de tempo
- Exibir:
  - Projeto
  - Tarefa
  - Data
  - Duração
  - Status

### 📄 Exportação PDF

- Gerar PDF do histórico
- Filtros:
  - Por período
  - Por projeto
- Layout limpo e profissional
